# Pomodoro

A simple, lightweight Pomodoro timer built with vanilla JavaScript. It helps you focus, take breaks, and stay productive without any heavy frameworks.

## Features
- Adjustable work and break durations
- Auto‑start next session option
- Keyboard shortcuts for quick control
- Sound notifications
- Responsive UI works on desktop and mobile

## Installation
1. Clone repo
   ```bash
   git clone https://github.com/muteksia/pomodoro.git
   cd pomodoro
   ```
2. Open `index.html` in a browser (no build step needed).

## Usage
- Click **Start** to begin a work session.
- Press **Pause** or hit `Space` to pause/resume.
- Switch between **Pomodoro**, **Short Break**, and **Long Break** tabs.
- Enable **Auto‑Start** in settings to let the timer jump to the next session automatically.
